# 入门教程

环境为 Ubuntu 22.04 + ROS 2 Humble + Bash。先完成[安装与构建](../usage/安装与构建.md)，再按顺序运行下面三个教程。它们共用四轮车组合 Xacro、SDF 办公场景和原生 PointCloud2，完成一个教程后停止其仿真，再进入下一个。

| 教程 | 学会什么 | 完成标志 |
| --- | --- | --- |
| [启动并控制小车](启动与控制.md) | 加载环境、启动仿真、读取传感器、发送速度、退出 | 数据连通，控制后里程计位移超过 1 cm |
| [添加一个 IMU](添加IMU.md) | 在自己的组合模型中添加安装坐标、固定关节和插件 | `/imu/tutorial` 有消息，frame 和安装 TF 正确 |
| [编写 ROS 2 消费节点](ROS2接入.md) | 使用仿真时间、匹配 QoS、订阅数据并显式启用控制 | 客户端输出 `success: true`，可正确识别缺失输入 |

本组教程的运行命令由[教程检查器](../../scripts/checks/check_documented_tutorials.py)直接读取，检查范围与实际执行状态见[版本与验证状态](../版本与验证状态.md)。教程通过只证明这些操作和接口可用，不代表外部 SLAM/Nav2 闭环通过。

完成后按任务进入[使用手册](../usage/README.md)；查询字段、单位和限制进入[接口参考](../api/README.md)。
