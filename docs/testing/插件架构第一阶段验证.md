# 插件架构第一阶段验证

2026-10-19，本阶段验证环境为 macOS arm64 / RoboStack ROS 2 Humble。结果仅覆盖已接入的底盘与编码器里程计插件，不代表整个插件化目标已完成。

| 验证 | 实际结果 |
|---|---|
| pluginlib、参数文件/覆盖、运动学、编码器、核心碰撞 | 26/26 通过 |
| 原有核心回归 | 173/173 通过 |
| 真实 ROS 话题、odom/真值横向速度分离、TF、session reset | 5/5 通过 |
| 核心之外独立编译和安装的里程计插件 | 通过：真实位移 1 m，外部 odom 1.25 m |
| 外部包构建前后核心可执行文件 SHA-256 | 相同：`ffec779f963ad58ac0345f5f6e01615f244389fa142b1ae88a9a29c96ef0d50b` |
| 原四轮机械 URDF | 与改造前 SHA-256 一致，文件未修改 |
| 包版本与发布包依赖图静态检查 | 版本一致；21 个正常构建包无依赖环，外部示例单独构建 |

运动验证包括两轮/同侧等速四轮差速、阿克曼内外转角和反向、禁止阿克曼零速原地旋转、三轮/四轮普通全向横移和旋转、矩阵奇异布局拒绝、时间步长分割、积分与随机序列 reset、碰撞后两种驱动累计策略、倒退脱离接触，以及转向轮自身的碰撞约束。ROS 测试通过真实进程和消息验证差速、四轮全向及 session reset。

新增转向碰撞测试发现：极小安全步长分支已阻止轮子继续转向，却没有记录接触事件。已补齐事件记录，并在修复后重新通过上述测试。核心与 ROS 运行结果使用修复后的构建；没有把先前失败运行计为通过。

证据位于工作区 `artifacts/evidence/plugin-architecture-20261019/`：

- `result.json`：阶段状态、测试数量、源码指纹、机械文件不变证明和剩余工作。
- `plugin-contracts.xml`、`core-regression.xml`、`ros-plugins.xml`：测试明细。
- `external-plugin.json`、`external-runtime.json`：外部包构建前后核心哈希及真实运行结果。
- `baseline.json`、`baseline-tracked.patch`、`baseline-untracked/`：改造前已有变更。
- `changes.patch`：当前全部工作区差异，包含此前已授权的固定障碍物改动，可结合基线区分。

复现底盘/里程计和外部包验收：

```bash
# 先 source ROS 2 环境，在仓库根目录执行。
bash scripts/test_plugins.sh /tmp/litesim3d-plugins
source /tmp/litesim3d-plugins/install/setup.bash
bash scripts/test_external_plugin.sh /tmp/litesim3d-external-test /tmp/litesim3d-plugins/install
```

ROS 测试还需要在同一安装空间构建 `litesim3d_interfaces`、`litesim3d_ros2`、`litesim3d_test_support`，然后执行 `python3 -m pytest -q litesim3d_ros2/test/test_plugins_ros.py`。当前实际隔离构建目录为 `/private/tmp/litesim3d-plugins-20261019`。
