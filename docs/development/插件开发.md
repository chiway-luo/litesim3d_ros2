# 插件开发

本页介绍创建、安装和验证外部插件的流程。C++ 生命周期、输入输出结构、模型扩展标签、参数优先级和标准实现清单统一见 [插件接口](../api/插件接口.md)。使用已有插件见 [模型组合与插件迁移](../usage/模型组合与插件迁移.md)。

## 实现与安装

1. 建立独立 ament_cmake 包，按类别继承 ChassisPlugin、OdometryPlugin 或 SensorPlugin。
2. 实现 defaults、initialize、step 和 reset；参数校验、单位和输出布局遵循接口文档。
3. 使用 `PLUGINLIB_EXPORT_CLASS` 导出基类，在 CMake 调用 `pluginlib_export_plugin_description_file(litesim3d_plugin_api plugins.xml)`。
4. 安装共享库、plugins.xml、config；在机器人模型的 class 中选择实现，参数放在独立文件。
5. 单独构建外部包，加载其 overlay 后重新启动仿真，检查运行清单中的实际类和参数。

底盘与里程计依赖公共 API；传感器还依赖已安装核心 SDK，用于公共场景、射线、随机流和测量数据。核心不链接具体实现包。参考完整 [external_plugins](../../examples/external_plugins/README.md) 示例，不需要向内核增加插件类白名单。

## 编译与验证

source ROS 2 Humble 及系统依赖后，在仓库根目录执行：

```bash
bash scripts/test_plugins.sh /tmp/litesim3d-plugins
source /tmp/litesim3d-plugins/install/setup.bash
bash scripts/test_external_plugin.sh /tmp/litesim3d-external-test /tmp/litesim3d-plugins/install
```

第一条命令在独立目录编译接口、核心、各实现包和契约测试。第二个脚本只编译外部示例包，实际让既有 `sim_headless` 加载新插件，并比较构建前后的核心可执行文件、核心共享库及 API 共享库哈希。不会替换当前工作区的安装软链接或重启已运行的仿真。

插件实现使用 `PLUGINLIB_EXPORT_CLASS` 导出基类，并在自己的 CMake 中调用 `pluginlib_export_plugin_description_file(litesim3d_plugin_api plugins.xml)`。发布时安装共享库和 `config/`，由 ament 索引发现，不向核心加入实现名称白名单。主工程 C++ API/ABI 变更后，插件需针对同版接口重新编译。

## 修改时验证

新增参数同步更新 defaults、完整参数 YAML、解析校验、接口文档和适用的契约测试。重点核对无效模型拒绝、编码器与真值隔离、reset 可重复性和插件加载生命周期；传感器还需核对输出字段、采样时间、噪声及多实例相互隔离。

测试结果与平台限制见 [插件架构完成验证](../testing/插件架构完成验证.md) 和 [传感器插件验证](../testing/传感器插件验证.md)。本页的命令是复现入口，不代表本次文档调整重新执行了这些测试。
