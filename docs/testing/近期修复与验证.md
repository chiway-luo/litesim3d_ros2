# 近期修复与验证

记录日期：2026-10-18。以下均为本机 macOS arm64 / RoboStack ROS 2 Humble 的实际执行结果。报告对应当时的源码与证据；原始文件位于外部 `evidence/`，路径解析见 [测试入口](README.md)。

## 重置后首帧偶发超时

旧管理器把“节点已发现”当作消费端就绪。节点可能在创建订阅和处理 executor 前已可见；DDS 发现也可能早于 ROS 图补齐端点归属。此时立即单步发布的 volatile / best effort 首帧可能丢失，暂停后没有后续帧补发。

延后 1.5 秒创建订阅的复现中，旧 reset 比订阅创建提前 1476 ms 返回；仿真发布了首帧，但消费端收到 0 帧。修复后，管理器确认成员参数服务能响应、当前 run_id 的状态已更新、输入订阅类型/QoS 与 DDS 匹配已就绪，再返回成功。可用 `ready_topics` 显式声明异步创建的输入；重置期间保持暂停，不通过额外仿真步绕过问题。
