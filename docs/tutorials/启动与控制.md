# 启动并控制小车

目标：启动办公区四轮车，读取雷达、IMU、里程计和仿真时钟，让小车行驶并验证位移。机器人由组合 Xacro 提供，环境由 SDF 提供。案例独立启动 RSP、controller_manager、diff_drive_controller 和 joint_state_broadcaster；/cmd_vel 由控制器订阅，公共仿真 launch 不包含这些节点。首次验收关闭窗口和相机；通过后可再打开可视化。

## 前置条件

- 已完成[安装与构建](../usage/安装与构建.md)，安装空间能找到 `wheel_car_4w_sim`。
- 使用 Ubuntu 22.04、ROS 2 Humble、Bash；下列命令从克隆的源码仓库根目录执行。
- 本教程使用的 ROS domain 中没有其他仿真。每个终端使用相同 domain。

<a id="environment"></a>
## 1. 准备两个终端

在终端 A 和 B **分别执行**：

```bash
source /opt/ros/humble/setup.bash
source "$(python3 scripts/paths.py install)/setup.bash"
export ROS_DOMAIN_ID=70 ROS_LOCALHOST_ONLY=1
```

标准 colcon 工作空间用户将第二条替换为自己工作空间的 `source install/setup.bash`。不要混用不同安装空间。

## 2. 启动办公区四轮车

终端 A：

<!-- tutorial-command: car-launch -->
```bash
ros2 launch wheel_car_4w_sim wheel_car_4w.launch.py gui:=false rviz:=false cameras:=false lidar_profile:=vlp16 lidar_interface:=native
```

等待启动完成，保持终端 A 运行。没有窗口是本步骤的预期行为。这里显式选择 VLP-16 和原生消息，避免雷达预设变化影响教程。

## 3. 验证数据

终端 B：

<!-- tutorial-command: car-observe -->
```bash
python3 docs/examples/ros_client.py --duration 10 --require-imu
```

程序不发送速度，结束后输出 JSON，退出码为 0。应同时满足：

- `connected` 和 `success` 为 `true`；
- `counts.clock`、`counts.points`、`counts.imu`、`counts.odom` 都大于 0；
- `clock_ns` 大于 0，`cloud.fields` 包含 `x`、`y`、`z`、`ring`、`time`；
- `frames` 中有非空点云、IMU 和里程计 frame。

计数受电脑速度、DDS 发现时间和调度影响，不要求与示例文字完全相同。失败时程序返回非零，并在 `checks` 中指出失败项。

## 4. 发送速度并验证运动

仍在终端 B：

<!-- tutorial-command: car-drive -->
```bash
python3 docs/examples/ros_client.py --drive --linear 0.1 --angular 0.0 --duration 8 --require-imu --require-motion
```

程序以 10 Hz 墙钟频率发送 Twist，退出前发送零速度。成功条件是传感器连通、确实发送了非零命令，并且观察到至少 1 cm 的里程计位移：`checks.motion` 为 `true`。这验证控制链路与里程计反馈，不证明避障或定位精度。

想手动控制时，可用[日常运行](../usage/接入与使用手册.md#控制与停车)中的 `ros2 topic pub`。

## 5. 查看和退出

在终端 A 按 Ctrl+C，等待整组 launch 退出。查看三维窗口时，重新执行第 2 步，把 `gui:=false` 改为 `gui:=true`；需要 RViz 再把 `rviz:=false` 改为 `rviz:=true`。相机保持关闭，桌面/图形后端问题按[排障手册](../usage/记录与排障.md)处理。

停止速度发布后，小车按配置减速；默认命令超时是 0.5 秒**仿真时间**。退出客户端与退出仿真是两个独立操作。

## 常见失败

| 现象 | 检查与处理 |
| --- | --- |
| 找不到包或消息类型 | 两个终端重新加载同一安装空间；确认构建无失败 |
| 所有计数为 0 | 比较 `ROS_DOMAIN_ID` 和 `ROS_LOCALHOST_ONLY`，查看终端 A 是否退出 |
| 点云为 0，其他数据正常 | 保持本教程的 `lidar_profile:=vlp16 lidar_interface:=native`；检查消息类型和 best effort QoS |
| 时钟或数据不再推进 | 检查是否暂停；在同一 domain 中只运行一个世界 |
| `checks.motion` 为 false | 查看 `counts.moving_commands`、首末 odom、碰撞与暂停状态；不要把延长时间当作修复接口错误 |
