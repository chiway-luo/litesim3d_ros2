# 文档规范化验证

日期：2026-10-20。对象：0.4.0 开发工作树中的教程、接口参考、文档检查器及文档站。本文仅记录本轮实际检查，不继承历史整仓验收结论。

## 范围

- 三篇教程使用四轮车组合模型与 SDF，关闭 GUI 和相机。
- 新 IMU 示例包含完整 Xacro、挂载 link/joint、runtime、消息与 TF 检查。
- 插件参数页从 12 个实现包的完整参数文件生成；6 个消息/服务 IDL 与接口页逐字核对。
- 文档检查增加章节锚点、页面标题、参数声明覆盖、生成表格新鲜度与负例。
- 文档站由同一份 Markdown 构建，原始文档保持不变。

## 证据与复现

原始证据在仓库外 `artifacts/evidence/documentation-standard-20261020/`，通过 `python3 scripts/paths.py evidence` 定位证据根目录：

- `runtime-1/result.json`：macOS 的逐项命令、源码哈希和结果。
- `linux/tutorial-results/result.json`：Ubuntu 的同组检查；stdout/stderr 与 launch 日志同目录保存。
- `linux/build-serial.log`、`linux/plugin-contracts.log`、`linux/core-plugin-contracts.log`：Linux 构建及插件契约结果。
- `linux-source.json`：上传到隔离 Linux 临时目录的源码清单、基准提交和归档哈希。快照不包含 `.git`，不能将其验证结果仅绑定到基准提交。
- `docs-check.json`、`api-check.json`、`checker-tests.log`：文档与接口静态检查。
- `runtime-packages.json`：Sphinx、MyST、主题、PyYAML 和 jieba 的实际版本与加载位置；运行环境检查和 `pip check` 均通过。
- `search-zh.png`、`imu-reference.png`、`diagrams.png`：实际浏览器截图。

最终站点保存在仓库外 `artifacts/docs/documentation-20261020/`，首页为 `html/index.html`，构建摘要为 `build-summary.json`，清单为 `.sphinx-converter/manifest.json`。临时预览服务器在检查后停止；重新预览按文档站说明启动本机回环地址的 HTTP 服务。

复现命令见[文档维护](../development/文档维护.md)。运行教程检查时使用未被占用的 ROS domain，输出到新的目录。GitHub Actions 修改尚未推送，不能把本地结果写成远端 CI 通过。
