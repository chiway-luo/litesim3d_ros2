# 启动与节点参数

适用版本以仓库 [VERSION](../../VERSION) 为准。本文按当前源码整理；操作步骤见 [使用手册](../usage/README.md)。

## 参数层次与生效时间

模型/传感器参数属于组合模型声明或 YAML；launch 参数以 `参数:=值` 传入；节点参数以 ROS 参数文件或 `--ros-args -p` 传入。以下设置在启动时读取，不支持靠 `ros2 param set` 热更新模型、类型、QoS 或发布器。每个 launch 只接受自己声明的参数。

## 通用组合模型与 SDF 启动器

入口：`ros2 launch litesim3d_bringup simulation.launch.py`。源码：[simulation.launch.py](../../litesim3d_bringup/launch/simulation.launch.py)。车型 launch 提供安装路径默认值；下表同时列出通用值与四轮车覆盖值。

| 参数 | 通用默认值 | 四轮车默认值 / 约束 |
| --- | --- | --- |
| `assets_root` | 空 | `wheel_car_4w_models` 的 share；SDF 模式必填 |
| `world` | 空 | `office.sdf`；单文件名相对 assets_root/worlds，否则按路径读取 |
| `runtime` | 空 | `wheel_car_4w_sim/config/runtime.yaml`；SDF 模式必填 |
| `params` | 必填 | `wheel_car_4w_sim/config/ros.yaml` |
| `model_arguments` | `{}` | Xacro 参数 YAML 映射 |
| `config` | 空 | 非空选择直接 YAML 兼容入口，此时不用 SDF 查看器 |
| `gui` | true | 只读三维窗口开关 |
| `cameras` | 空 | 沿用逐实例 enabled；true/false 覆盖全部标准相机；仅 SDF 模式 |
| `camera_view` | false | 启动可选图像预览，不改变相机类型 |
| `collision_budget_enabled` | false | 加载时的碰撞复杂度预算开关 |
| `real_time_factor` | 空 | SDF 模式沿用 physics；0 不限速；范围 [0,100] |
| `lidar_profile` | config | 沿用模型；预设要求恰好一个标准雷达 |
| `lidar_profiles_dir` | 空 | 四轮车 config/lidars 目录 |
| `noise_config` | 空 | 可选误差 YAML；按传感器实例名覆盖，最后应用，见 [误差配置](配置文件.md#noise-config) |
| `lidar_interface` | auto | native / auto / livox；auto 仅对 Mid-360 选择 Livox 输出 |
| `xfer_format` | 1 | Mid-360：1=CustomMsg，0=Livox PointCloud2 |
| `livox_lidar_id` | 0 | [0,255]，写入 CustomMsg |
| `rviz` | false | 启动 RViz |
| `rviz_config` | 桥接包 rviz/demo.rviz | 四轮车空值自动按预设选择；显式路径优先 |
| `paused` | 空 | 沿用 params 的 start_paused；true/false 显式覆盖 |
| `manifest` | 空 | 沿用节点配置；非空覆盖 manifest_path，父目录须存在 |

`params` 只接受 `/**`、`/litesim3d`、`/robot_state_publisher`、`/rviz2` 四类节，各节只有 `ros__parameters` 映射；通用节先合并，专用节覆盖。三个节点的最终 `use_sim_time` 必须为 true。launch 再写入生成的 config/URDF、frame 前缀、场景与显式覆盖值。

`model_arguments` 先参与 Xacro 展开；非空 `cameras` 后覆盖标准相机开关。SDF 的时钟与出生位姿规则见 [配置文件](配置文件.md#sdf-runtime)。无人机默认资源包是 `drone_3d_models`、世界 `drone_arena.sdf`；其他车型以各自 launch 为准。

## 单机 `demo.launch.py`

| launch 参数 | 默认 | 说明 |
| --- | --- | --- |
| `config` | 安装目录的 `config/demo.yaml` | 单机 YAML 文件路径，推荐绝对路径 |
| `namespace` | 空 | ROS 命名空间，如 `robot` |
| `frame_prefix` | 空 | TF/frame 前缀，如 `robot/`，无前导 `/`，有结尾 `/` |
| `paused` | `false` | 就绪后保持暂停 |
| `rviz` | `true` | 启动随附 RViz |
| `manifest` | 空 | 非空时写运行 JSON，父目录先创建 |

查看实际安装版本：

```bash
ros2 launch litesim3d_ros2 demo.launch.py --show-args
```

此 launch **未暴露** `cmd_mode`、`sensor_reliable`、`publish_odom_tf` 等节点参数。需要这些设置时用[手册的独立节点方式](../usage/接入与使用手册.md#advanced-start)，或在自己的 ROS launch 中向 Node 的 `parameters` 传入。不要把未声明的参数写在 demo launch 后并假定它生效。

## 单机节点参数表

| `sim_node` 参数 | 默认 | 说明 |
| --- | --- | --- |
| `config` | 空，必须提供 | 单机 YAML 文件路径 |
| `use_sim_time` | ROS 通用参数；launch 设为 true | 算法、RSP、RViz 也应启用 |
| `frame_prefix` | 空 | 同时影响消息 frame 和桥接发布的 TF |
| `cmd_mode` | `twist` | `twist` / `stamped`；一个话题只选一种 |
| `sensor_reliable` | false | false 为 best effort，true 为 reliable；点云/IMU KEEP_LAST 5 |
| `publish_odom_tf` | true | 是否发布 `odom → URDF root` |
| `external_odom_tf` | false | 外部发布责任声明；与 `publish_odom_tf: true` 同时启用会拒绝 |
| `wait_for_robot_state_publisher` | true | 等待同命名空间、指定名称的 RSP 订阅 joint_states |
| `robot_state_publisher_name` | `robot_state_publisher` | RSP 节点名，不是包名或 TF frame |
| `startup_timeout` | 10.0 | 正数，等待依赖的墙钟秒数 |
| `start_paused` | false | 依赖就绪后是否暂停 |
| `manifest_path` | 空 | 运行清单输出路径 |
| `initial_pose_override` | 空数组 | 可选 7 个 double：`[x,y,z,qx,qy,qz,qw]`，主要用于会话重置 |
| `scene_description` | 空 | SDF 导入的 scene.json；启用场景通道与相机渲染配置 |
| `viewer_ready_file` | 空 | 启动器内部渲染就绪文件，非用户模型配置 |
| `lidar_interface` | native | native / auto / livox；节点默认与通用 launch 的 auto 不同 |
| `xfer_format` | 1 | 1=CustomMsg，0=Livox PointCloud2 |
| `livox_lidar_id` | 0 | [0,255] |
| `test_drop_frames` | 0 | 测试故障注入，0–100；正常使用保持 0 |

若外部估计器发布 odom TF，独立 sim_node 加 `-p publish_odom_tf:=false -p external_odom_tf:=true`。关闭等待 RSP 不会自动补齐内部 link TF，常规使用保留等待。

## 多机 `world.launch.py`

| launch 参数 | 默认 | 说明 |
| --- | --- | --- |
| `config` | 安装目录的 `config/m3_world.yaml` | 世界配置路径 |
| `paused` | false | 整个世界暂停启动 |
| `manifest` | 空 | 整个世界运行清单 |
| `cmd_mode` | twist | 所有机器人的命令类型统一选择 |
| `sensor_reliable` | false | 所有机器人的点云/IMU可靠性统一选择 |
| `publish_odom_tf` | true | false 时全部机器人的 odom TF 交给外部估计器 |
| `external_odom_tf_robots` | 空 | 逗号分隔 ID，如 `r1,r3`；仅关闭这些机器人的 odom TF |
| `startup_timeout` | 15.0 | 正数，等待各 RSP 的墙钟上限 |

world launch 没有 `rviz`、`namespace` 或 `frame_prefix` 参数。每个 ID 自动成为 namespace 和 frame 前缀。布尔设置写 `true`/`false`。

直接使用 `sim_world_node` 时，节点参数为 `config`、`use_sim_time`、`start_paused`、`manifest_path`、`cmd_mode`、`sensor_reliable`、`publish_odom_tf`、`external_odom_tf_robots`、`wait_for_robot_state_publisher`、`robot_state_publisher_name`、`startup_timeout`。默认值与上表/单机等待设置一致，startup_timeout 为 15.0；其中 `external_odom_tf_robots` 是字符串数组，launch 的逗号文本会转换为数组。另支持节点参数 `lidar_interface=native`、`xfer_format=1`、`livox_lidar_id=0`，当前 world launch 未暴露这三项。没有单机的 `initial_pose_override`、`external_odom_tf`、`test_drop_frames`、`scene_description` 和 `viewer_ready_file` 参数。使用 world launch 可自动管理各机器人的 RSP。

## 会话、适配器与命令行

| 程序 | 参数 / 默认值 | 行为 |
| --- | --- | --- |
| `sim_session` | `--config`、`--output` 必填 | 单机 YAML；每次启动使用新的输出目录 |
| 同上 | `--members` 可选 | JSON 成员列表；name、argv 必填，ready_topics 可选；最多 32 个 |
| 同上 | `--observer` 可重复 | 只读观察节点名；不能豁免控制发布者 |
| 同上 | `--timeout 15` | [1,120] 墙钟秒，启动/重建等待上限 |
| 同上 | `--sensor-reliable` 默认关闭 | 子节点雷达/IMU 使用 reliable；接收方也须匹配 |
| `sim_ouster_adapter` | `input_topic=points_raw`、`output_topic=points_ouster` | ROS 参数；输入必须是 xyzirt_v1 |
| 同上 | `sensor_reliable=false` | 同时作用于输入输出；KEEP_LAST 5 |
| `sim_cloud_probe` | `sensor_reliable=false` | 固定订阅 points_ouster（可 remap），输出 probe_status |
| `sim_headless` | `CONFIG STEPS OUTPUT [V] [W] [RTF]` | STEPS 1–10000000；可选 V/W/RTF 默认 0；该 RTF 决定 CLI 节拍 |
| `prepare_config` | 位置参数 `CONFIG OUTPUT` 必填；`--world`、`--noise-config` 可选 | 展开组合模型，按需导入 SDF；输出目录须为空 |

`sim_session` 的成员 argv 直接执行，不展开 shell 变量。启动与 reset 的就绪规则见 [消息与服务](消息与服务.md#reset)，实际操作见 [会话与重置](../usage/会话与重置.md)。命令行完整选项以 `--help` 为准。
