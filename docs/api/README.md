## 接口范围

| 入口 | 对外能力 | 限制 |
| --- | --- | --- |
| `litesim3d_bringup/simulation.launch.py` 与车型 launch | 组合 Xacro、SDF 场景、单机 ROS 2、可选图形/相机 | 开启相机需要渲染后端 |
| `litesim3d_ros2/demo.launch.py` | 基础单机 YAML，雷达/IMU、控制和评测 | 直接加载已展开 URDF；不自动提供相机渲染服务 |
| `litesim3d_ros2/world.launch.py` | 1–4 台同构机器人共享时钟与碰撞世界 | 无多机会话 reset；不支持启用相机 |
| `litesim3d_ros2/sim_session` | 根命名空间单机与登记消费端的协调重置 | 使用基础单机配置；不替代 SDF 图形启动器 |
| `sim_headless` / C++ SDK | 核心步进、传感器计算、运行清单 | 无 ROS 话题；无相机渲染服务 |

正式接口以本目录链接的 IDL、公开头文件、launch 声明及解析器为依据。JSON 诊断和运行清单是实现相关数据，应容忍新增字段；未知必填配置、非法值和不支持的组合在加载时拒绝。插件 `api_version=1` 不表示跨版本二进制兼容承诺，升级核心后需用对应接口重新编译外部插件。
