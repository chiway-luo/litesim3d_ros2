# litesim3d_rgb_camera

插件类：`litesim3d_rgb_camera/RgbCamera`；类别：`SensorPlugin`。

本表所有参数在启动时读取。`number` 接受有限实数；数组长度、单位、范围和关联条件见说明列。
必填项没有默认值；请在机器人配置中提供实际值。可选项为实现缺省值，车型配置可以覆盖。

来源：[parameters.yaml](../../../plugins/litesim3d_rgb_camera/config/parameters.yaml)、[实现](../../../plugins/litesim3d_rgb_camera/src/plugin.cpp)。

| 字段 | 类型 | 默认值 | 单位、范围与含义 |
| --- | --- | --- | --- |
| `link` | string | 无；必填 | 必填示例：URDF 光学 link，+z 前、+x 右、+y 下；安装姿态由 URDF joint 给定。 |
| `topic` | string | 无；必填 | 必填示例：话题前缀；发布 color 或 depth 下的 image_raw 和 camera_info。 多实例必须使用不同输出话题；只允许相对话题。 |
| `enabled` | boolean | `true` | 是否启用采样；false 仍校验参数和 link。 |
| `width` | integer | `640` | 水平像素数，整数 [16,4096]；单相机总像素 ≤8294400。 |
| `height` | integer | `480` | 垂直像素数，整数 [16,4096]。 |
| `rate_hz` | number | `15.0` | 帧率，Hz，(0,240]；以仿真时钟调度，渲染变慢时降低实际推进速度。 |
| `horizontal_fov_deg` | number | `70.0` | 水平针孔视场，度，(0,180)，纵向内参由宽高推导。 |
| `near_clip_m` | number | `0.1` | 最近裁剪距离，m，必须 >0；深度为光学 z 方向距离。 |
| `far_clip_m` | number | `20.0` | 最远裁剪距离，m，必须大于最近距离；无效深度输出 NaN。 |
| `color_bias_dn` | number[] | `[0.0,0.0,0.0]` | RGB 三通道固定偏差，像素 DN，有限数；输出取整并裁剪到 [0,255]。 |
| `color_sigma_dn` | number[] | `[0.0,0.0,0.0]` | RGB 三通道独立高斯噪声标准差，DN，各项 ≥0。 |

未知字段、错误类型、非法数值或缺失必填项会在加载阶段报错。含禁用传感器的配置仍须满足参数与挂载要求。坐标/关节条件见[坐标与模型约定](../坐标与模型约定.md)。
