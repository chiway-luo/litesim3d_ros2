# litesim3d_ackermann_odometry

插件类：`litesim3d_ackermann_odometry/AckermannOdometry`；类别：`OdometryPlugin`。

本表所有参数在启动时读取。`number` 接受有限实数；数组长度、单位、范围和关联条件见说明列。
必填项没有默认值；请在机器人配置中提供实际值。可选项为实现缺省值，车型配置可以覆盖。

来源：[parameters.yaml](../../../plugins/litesim3d_ackermann_odometry/config/parameters.yaml)、[实现](../../../plugins/litesim3d_ackermann_odometry/src/plugin.cpp)。

| 字段 | 类型 | 默认值 | 单位、范围与含义 |
| --- | --- | --- | --- |
| `wheel_radius_m` | number | 无；必填 | 必填：四轮统一有效半径，m，必须 > 0；以下均为示例几何。 |
| `wheelbase_m` | number | 无；必填 | 必填：后轴到前轴距离，m，必须 > 0；base 原点必须位于后轴中点。 |
| `track_width_m` | number | 无；必填 | 必填：左右轮距，m，必须 > 0；左 y=+轮距/2，右 y=-轮距/2。 |
| `rear_left_joint` | string | 无；必填 | 必填：后左 continuous 驱动轮关节，位于 [0,+轮距/2]，中立轴 +y。 |
| `rear_right_joint` | string | 无；必填 | 必填：后右 continuous 驱动轮关节，位于 [0,-轮距/2]，中立轴 +y。 |
| `left_steering_joint` | string | 无；必填 | 必填：左 revolute 转向关节，中立角 0，轴 +z；不得 mimic。 |
| `right_steering_joint` | string | 无；必填 | 必填：右 revolute 转向关节，约定同左侧；两侧转角按同一转弯中心分别计算。 |
| `max_steering_rad` | number | `0.6` | 单个实际前轮（含内轮）的转角绝对值上限，rad，(0,pi/2)；须落在 URDF 限位内。 理想位置执行器在积分区间开始选定角度，不模拟舵机动力学；零速不能原地旋转。 |
| `noise` | object | 见子字段 | 编码器解算后的速度误差；位姿按每个实际时间段积分，reset 重置随机序列。 |
| `noise.linear_scale_error` | number[] | `[0.0,0.0]` | [x,y] 速度相对比例误差，无量纲，每项 > -1；0 理想，0.02 表示 +2%。 |
| `noise.angular_scale_error` | number | `0.0` | yaw 角速度相对比例误差，无量纲，> -1；0 理想。 |
| `noise.linear_scale` | number[] | `[1.0,1.0]` | 兼容旧配置：速度倍率，理想为 1；不能和非零 linear_scale_error 同时使用。 |
| `noise.linear_bias_mps` | number[] | `[0.0,0.0]` | 车体 [x,y] 两方向速度偏置，m/s，有限实数；非零可造成静止漂移。 |
| `noise.linear_sigma_mps` | number[] | `[0.0,0.0]` | 车体 [x,y] 两方向独立高斯速度噪声标准差，m/s，每项 >= 0。 |
| `noise.angular_scale` | number | `1.0` | 兼容旧配置：yaw 速度倍率，理想为 1；不能和非零 angular_scale_error 同时使用。 |
| `noise.angular_bias_radps` | number | `0.0` | yaw 速度偏置，rad/s，有限实数。 |
| `noise.angular_sigma_radps` | number | `0.0` | yaw 高斯速度噪声标准差，rad/s，必须 >= 0；seed 来自仿真。 |

未知字段、错误类型、非法数值或缺失必填项会在加载阶段报错。含禁用传感器的配置仍须满足参数与挂载要求。坐标/关节条件见[坐标与模型约定](../坐标与模型约定.md)。
