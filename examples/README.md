# 车型与扩展示例

第一次运行先完成[小车教程](../docs/tutorials/启动与控制.md)。本页用于选择其他运动模型、查找完整资源包或学习外部插件。

| 示例 | 用途 |
| --- | --- |
| [四轮小车](wheel_car_4w/README.md) | 组合模型、办公场景、雷达和 IMU 的完整启动工程 |
| [无人机](drone_3d/README.md) | 三维速度控制与场景接入；不含飞行动力学 |
| [阿克曼](ackermann/README.md) | 转向约束与轮式里程计 |
| [三轮全向](omni3/README.md) | 三轮普通全向底盘 |
| [四轮全向](omni4/README.md) | 四轮普通全向底盘 |
| [外部里程计插件](external_plugins/README.md) | 独立安装、加载和替换插件 |

调整配置前先查[逐插件参数](../docs/api/plugins/README.md)；新增自己的模型按[模型接入](../docs/usage/模型接入.md)组织资源。
