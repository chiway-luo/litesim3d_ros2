# 使用手册

按当前任务选择入口，不需要顺序读完所有页面。第一次使用从[入门教程](../tutorials/README.md)选择。字段、默认值与错误语义见[接口参考](../api/README.md)，适用范围见[版本与验证状态](../版本与验证状态.md)。

## 第一次运行

要从自己的 description 出发搭完整环境，使用[双 MID-360 完整流程](../tutorials/双MID360从零搭建.md)，包含克隆、独立 bringup、world 配置、URDF 传感器、launch 编写与启动控制。

[安装与构建](安装与构建.md) → [启动并控制小车](../tutorials/启动与控制.md) → [添加 IMU](../tutorials/添加IMU.md) → [ROS 2 消费节点](../tutorials/ROS2接入.md)。全程使用同一个四轮车组合模型和 SDF 场景。
