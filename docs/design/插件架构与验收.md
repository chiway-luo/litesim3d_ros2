# LiteSim3D 插件架构与验收

2026-10-19 完成当前改造及 macOS arm64 / RoboStack Humble 验证。本文件记录最终接口、兼容决定和逐项验收；实际测试统计、证据与未验证范围见 [完成验证](../testing/插件架构完成验证.md)。

## 包边界

- `litesim3d_plugin_api`：版本化 C++ 接口、数据类型、pluginlib 加载器和公共数值工具，不包含具体底盘实现。
- 每种底盘、里程计、传感器的具体实现分别放入独立 ROS 2 包；核心只依赖接口，运行时根据类名加载。
- 核心负责时间、命令超时、碰撞、真实状态、场景和资源；插件负责对应模型或测量算法。现有射线和渲染能力作为公共服务复用。
- 安装新插件只需要编译新包并 source 安装空间，无须修改、重新编译核心。只支持启动时选择插件，不支持运行中卸载或替换。

## 接口与状态流

坐标统一为右手系：车体 x 前、y 左、z 上，正 yaw 绕 +z。时间戳和时间步长使用整数纳秒；关节角 rad、角速度 rad/s、长度 m。

1. `ChassisPlugin` 接收车体速度命令、上一时刻驱动速度、关节状态与步长，返回区间平均/末端车体速度、轮子转角增量、转向关节目标角与末端关节速度。不读取场景或真实位姿。
2. 核心根据输出检查碰撞，提交受约束的真实位姿和关节状态。开启 `continue_on_collision` 时驱动编码器继续积分；关闭时只提交碰撞前的驱动增量并停止驱动。障碍物始终固定。
3. `OdometryPlugin` 只接收编码器前后位置、末端速度、转向角与步长，返回自己积分的 odom 位姿和速度。接口不提供真实位姿。
4. `SensorPlugin` 接收真实姿态、运动状态、挂载变换和采样时间，利用公共射线/渲染服务输出数据；不使用轮式 odom 位姿。

生命周期：加载器按声明创建实例；`initialize` 校验全部参数及 link/joint 引用；`step` 只在仿真线程调用；`reset` 清理积分、随机序列和采样状态；退出时先析构实例，再销毁加载器。参数更改通过新建仿真会话生效。

差速支持左右两组同速普通轮。阿克曼采用后轴中点为运动参考，分别计算内外转向角和四轮转速，禁止零速原地旋转。三轮、四轮全向采用普通全向轮（自由滚子允许横向滑动），逐轮声明位置、滚动方向和半径，检查运动学矩阵满秩；不把麦克纳姆轮视作同一模型。

## 模型与配置契约

原始机械 URDF 保持逐字节不变；`simulation.urdf.xacro` include 原始模型及 `sensors.xacro`，声明底盘、里程计插件。传感器文件定义新增安装 link/joint 与对应插件。RSP 和核心使用同一份展开 XML。

扩展解析格式为：`<litesim3d version="1"><chassis|odometry|sensor name="..." class="..."><parameters file="package://包/config/parameters.yaml" section="可选子节"/><overrides>YAML 映射</overrides></...></litesim3d>`。参数优先级是实现默认值 < 按声明顺序合并的参数文件 < 实例 overrides。映射递归合并，序列整体替换；未知参数直接报错。四个地面机器人示例使用正式组合 Xacro，底盘、里程计和五种传感器均已接入运行时。

每个插件的 `config/parameters.yaml` 必须包含全部可配置项和中文注释；必填项写可运行示例值，可选项写实现默认值。schema 与参数文件键集合由测试比较。机器人使用一个几何参数来源供底盘和里程计引用，避免两份轮径/轮距漂移。

保留原有 launch 和 SDF 入口。旧 YAML 传感器列表适配为标准插件；旧底盘/odom 保留原有兼容计算路径，以便重现旧实验，新车型使用扩展插件。旧理想 Ackermann 与 multicopter 不冒充新的关节模型，迁移步骤和能力差异见 [模型组合与插件迁移](../usage/模型组合与插件迁移.md)。这是“保留兼容或提供明确迁移”的最终选择，不要求本次新增 multicopter 插件。

显式 chassis 与旧 `robot.drive`/`robot.motion_model` 冲突；显式 odometry 与旧 `odom` 冲突；任意显式 sensor 与非空的旧 `lidars`/`imus`/`cameras` 列表冲突。配置冲突直接报错。SDF 世界提供环境和 URDF root 出生位姿，组合模型提供机器人结构、渲染几何及插件；省略组合模型时保留旧 SDF 转换路径。

## 完成证据与边界

29 个包的逐包独立构建、安装和测试全部通过，已安装 SDK 的独立消费者也通过。发布检查先逐包安装，再逐包恢复当前源码执行测试，核心集成测试从安装空间发现下游传感器插件；任一运行包变化都会使测试缓存失效。最新包源码指纹与最终记录全部一致。

独立发布检查包含 357 个通过、19 个跳过的叶子测试；另以真实图形后端补测组合模型 RGB/RGB-D/多相机 3 项通过，传感器阶段还执行了四实例相机的噪声与受阻真值渲染测试。外部里程计包独立编译加载后，真值移动 1 m、odom 移动 1.25 m，核心可执行文件及核心/API 共享库哈希均不变。

工作区原安装软链接未切换，原仿真未重启，没有提交或推送。隔离的完整构建位于 `/private/tmp/litesim3d-plugins-20261019`。当前结果不覆盖 Ubuntu、全部 GUI 手动操作、正式性能/长稳或真实设备验收；这些限制不影响已验证的启动时插件扩展契约。插件不增加刚体受力、轮胎摩擦或飞行动力学。
