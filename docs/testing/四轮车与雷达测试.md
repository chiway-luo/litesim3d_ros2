历史结果对应当次版本；原始 `evidence/...` 不随仓库提交，位置见 [测试入口](README.md)。

Mid-360扫描修正后的本机验证：内核135项、无界面示例13项、共享world ROS短测4项和独立RViz图形启动1项通过。标准colcon入口复测13项示例用例通过，GUI项单独验证。当前Mid-360使用Livox官方逐点扫描表，保持200000槽/s；50帧在线校验覆盖完整4秒方向序列，共对照997847个未裁剪方向。参数及限制见 [雷达配置说明](../../examples/wheel_car_4w/雷达配置说明.md)，证据与单帧对比图见 Mid-360修正测试记录（`evidence/mid360-reference/README.md`）。

历史记录：雷达扩展测试（`evidence/lidar-profiles/README.md`）、最初四轮车交付测试（`evidence/wheel-car-4w/README.md`）。这些旧记录不代替新的扫描方向一致性验证。

在完成构建、source 安装后，可复现本例短测：

```bash
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python3 -m pytest -q \
  examples/wheel_car_4w/wheel_car_4w_sim/test/test_wheel_car_4w.py
```

也可以从项目根目录使用标准 colcon 测试入口（构建脚本采用 merged install）：

```bash
lws_prefix="$(python3 scripts/paths.py install)"
colcon --log-base "$(dirname "$lws_prefix")/log" test \
  --base-paths "$PWD" --packages-select wheel_car_4w_sim \
  --build-base "$(dirname "$lws_prefix")/build" \
  --install-base "$lws_prefix" --merge-install
colcon test-result \
  --test-result-base "$(dirname "$lws_prefix")/build/wheel_car_4w_sim" --verbose
```

默认跳过需要桌面的 GUI 用例；在可访问图形桌面（或已配置 Xvfb）的终端单独执行：

```bash
LWS_4W_GUI=1 PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python3 -m pytest -q \
  examples/wheel_car_4w/wheel_car_4w_sim/test/test_wheel_car_4w.py::test_rviz_starts_and_consumes_installed_model
```

测试包含安装目录加载、真实 DDS 点云/IMU、四轮位置和速度、TF 外参、暂停单步幂等、命令超时停车、Stamped/reliable/前缀配置、非法参数拒绝、必需子进程异常退出传播。RSP 故障用例故意终止它自己启动的 RSP，预期 launch 非零退出，不代表示例启动故障。

由于本次补齐了 mimic 速度输出，核心源码指纹会改变。此前 M3 的性能/检测器报告保留为历史记录，本例没有重新执行正式 B3、Linux、外部 SLAM/导航或长稳验收。
