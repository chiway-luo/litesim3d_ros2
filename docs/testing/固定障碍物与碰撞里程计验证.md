# 固定障碍物与碰撞里程计验证

验证日期：2026-10-19。环境：macOS arm64、RoboStack ROS 2 Humble，独立构建与真实本机 DDS 话题测试。

## 行为

- YAML/SDF 场景障碍物固定在初始位姿，不计算推动、位移、旋转或反弹。旧 YAML `motion` 经格式校验后忽略，并在 manifest 中列出实体 ID。
- 场景使用显式 collision；SDF link 完全缺失 collision 时使用该 link 的 visual，旧 YAML 独立角色实体缺失 collision 时使用 visual。机器人自身几何导入规则不变。
- `robot.drive.continue_on_collision` 内核默认 false；四轮小车的 `runtime.yaml` 和 `simulation.yaml` 显式开启。true 时，车体受到阻挡，驱动轮和 mimic 轮仍转动，平面轮式里程计、odom TF 与里程计路径继续累计。
- 真值里程计、激光、IMU、相机使用真实车体状态。ideal/noisy 均支持轮速积分；开启此开关后的 ideal 只代表不加测量误差，不保证与真值一致。外部激光/视觉里程计算法自行使用传感器估计。
- 保留限速、加减速、命令超时、暂停及新会话重置；倒车可离开接触边界。地形失去支撑等错误仍停止驱动。无人机拒绝该轮式开关。

直线碰墙测试：以 0.8 m/s 驱动 2 秒，车体停在约 x=0.35 m。开启参数时轮式里程计为 x=1.6 m、驱动轮速度为 8 rad/s，真实线速度为零；关闭时轮式里程计随车体停止。随后以 -0.5 m/s 倒车 0.5 秒，车体退至约 x=0.10 m，轮式里程计保留已有偏差。session reset 后，轮式里程计和轮子累计状态归零。
