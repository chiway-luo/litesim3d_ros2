# 插件架构完成验证

验证日期：2026-10-19。平台：macOS arm64 / RoboStack ROS 2 Humble。结果对应本地未提交源码，包指纹保存在证据中；不引用旧提交的 CI 结果证明本次改造。

底盘、轮式里程计和传感器已分别支持启动时 pluginlib 加载。12 个标准实现各自独立成包，另有公共 API 包与独立外部里程计范例。四轮小车已迁移到组合 Xacro，新增阿克曼、三轮全向和四轮全向运行示例。接口及逐项要求见 [架构与验收](../design/插件架构与验收.md)，配置与运行见 [模型组合与插件迁移](../usage/模型组合与插件迁移.md)。

## 关键可观测结果

- `continue_on_collision=true`：固定障碍挡住真实车体，轮角与编码器里程计继续累计；false 时只接受碰撞前的驱动增量并停止。激光、IMU、图像和 ground truth 保持真实状态。差速、阿克曼及全向路径均有对应测试。
- 差速两轮和同侧等速四轮分别验证；阿克曼测试内外转向、四轮转速、倒车、限位、禁止原地旋转与 reset；普通全向轮测试横移、旋转、各轮几何与奇异布局拒绝。
- 组合模型在 RSP 参数与场景描述中的 SHA-256 一致，新增传感器 link 都有固定关节及正确发布者；机器人视觉几何也来自这份 XML。
- 原机械 `wheel_car_4w.urdf` SHA-256 保持 `b37bd00ee61609e712264266a9b1a352cae316d5cca346b585d7e69394f04a3c`，与改造前逐字节一致。
- 外部插件将编码器里程计缩放为 1.25 倍：真实 x=1.0000000000000007 m，odom x=1.2500000000000009 m。构建前后 `sim_headless`、`liblitesim3d_core`、`liblitesim3d_plugin_api` 哈希一致，并再次核对与交付隔离安装中的文件一致。

## 首轮问题及修复

首轮失败和最终复验均保留，不把修复后结果写成首次即通过：

- 阿克曼满舵角在浮点运算后可能略超 URDF 精确限位；对最终关节角按有效限位裁剪，增加边界用例。
- 组合 URDF 渲染材质缺少公共渲染器要求的 transparency/cast_shadows 默认字段；导入时补齐，并增加导入断言，真实相机 3 项复验通过。
- RoboStack 的 Ogre 编译期资源路径带 NUL 填充；在当前进程中从有效 SDK 路径定位深度材质，保留调用者环境覆盖。传感器阶段的真实渲染复验通过。
- macOS 独立消费者/测试缺少相应共享库搜索路径；增加安装 RPATH 和新示例测试的接口库路径。launch 日志目录改到检查产物目录，避免依赖用户全局日志目录可写。
- lidar_profile 无效文件的旧错误提示在迁移后改变；恢复兼容提示。全向换向验证等待时间按实际加速度约束修正。
