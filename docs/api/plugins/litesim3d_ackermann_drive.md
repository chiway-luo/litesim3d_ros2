# litesim3d_ackermann_drive

插件类：`litesim3d_ackermann_drive/AckermannDrive`；类别：`ChassisPlugin`。

本表所有参数在启动时读取。`number` 接受有限实数；数组长度、单位、范围和关联条件见说明列。
必填项没有默认值；请在机器人配置中提供实际值。可选项为实现缺省值，车型配置可以覆盖。

来源：[parameters.yaml](../../../plugins/litesim3d_ackermann_drive/config/parameters.yaml)、[实现](../../../plugins/litesim3d_ackermann_drive/src/plugin.cpp)。

| 字段 | 类型 | 默认值 | 单位、范围与含义 |
| --- | --- | --- | --- |
| `wheel_radius_m` | number | 无；必填 | 必填：四轮统一有效半径，m，必须 > 0；以下均为示例几何。 |
| `wheelbase_m` | number | 无；必填 | 必填：后轴到前轴距离，m，必须 > 0；base 原点必须位于后轴中点。 |
| `track_width_m` | number | 无；必填 | 必填：左右轮距，m，必须 > 0；左 y=+轮距/2，右 y=-轮距/2。 |
| `rear_left_joint` | string | 无；必填 | 必填：后左 continuous 驱动轮关节，位于 [0,+轮距/2]，中立轴 +y。 |
| `rear_right_joint` | string | 无；必填 | 必填：后右 continuous 驱动轮关节，位于 [0,-轮距/2]，中立轴 +y。 |
| `front_left_joint` | string | 无；必填 | 必填：前左 continuous 轮关节，位于 [轴距,+轮距/2]，必须直接属于左转向关节。 |
| `front_right_joint` | string | 无；必填 | 必填：前右 continuous 轮关节，位于 [轴距,-轮距/2]，必须直接属于右转向关节。 |
| `left_steering_joint` | string | 无；必填 | 必填：左 revolute 转向关节，中立角 0，轴 +z；不得 mimic。 |
| `right_steering_joint` | string | 无；必填 | 必填：右 revolute 转向关节，约定同左侧；两侧转角按同一转弯中心分别计算。 |
| `max_steering_rad` | number | `0.6` | 单个实际前轮（含内轮）的转角绝对值上限，rad，(0,pi/2)；须落在 URDF 限位内。 理想位置执行器在积分区间开始选定角度，不模拟舵机动力学；零速不能原地旋转。 |
| `limits` | object | 见子字段 | 驱动速度限制；车体 x 前、y 左、z 上，正 yaw 绕 +z。 |
| `limits.max_linear_speed_mps` | number | `1.0` | 平移速度向量模长上限，m/s，必须 > 0。 |
| `limits.max_angular_speed_radps` | number | `2.0` | 绕 +z 角速度绝对值上限，rad/s，必须 > 0。 |
| `limits.acceleration_mps2` | number | `0.5` | 平移加速度上限，m/s²，必须 > 0。 |
| `limits.deceleration_mps2` | number | `1.0` | 减速或反向时的平移加速度上限，m/s²，必须 > 0。 |
| `limits.angular_acceleration_radps2` | number | `2.0` | yaw 角加速度上限，rad/s²，必须 > 0。 |
| `limits.unlimited_acceleration` | boolean | `false` | true：忽略加速度限制但保留速度与关节限制；false：使用上述加速度。 |

未知字段、错误类型、非法数值或缺失必填项会在加载阶段报错。含禁用传感器的配置仍须满足参数与挂载要求。坐标/关节条件见[坐标与模型约定](../坐标与模型约定.md)。
