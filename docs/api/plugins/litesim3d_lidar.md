# litesim3d_lidar

插件类：`litesim3d_lidar/Lidar`；类别：`SensorPlugin`。

本表所有参数在启动时读取。`number` 接受有限实数；数组长度、单位、范围和关联条件见说明列。
必填项没有默认值；请在机器人配置中提供实际值。可选项为实现缺省值，车型配置可以覆盖。

来源：[parameters.yaml](../../../plugins/litesim3d_lidar/config/parameters.yaml)、[实现](../../../plugins/litesim3d_lidar/src/plugin.cpp)。

| 字段 | 类型 | 默认值 | 单位、范围与含义 |
| --- | --- | --- | --- |
| `link` | string | 无；必填 | 必填示例：URDF 中存在的安装 link；+x 为扫描正前方，+y 左，+z 上。 |
| `topic` | string | 无；必填 | 必填示例：PointCloud2 话题；多机器人使用相对话题，每个实例不能重名。 |
| `enabled` | boolean | `true` | 是否启用采样；false 保留声明与参数校验，不产生数据。 |
| `rate_hz` | number | `10.0` | 每秒帧数，Hz，(0,1000]；滚动扫描一帧覆盖 1/rate_hz 秒。 |
| `columns` | integer | `1024` | 每圈/帧的列数，整数 [1,65536]；列数×线数 ≤ 4194304。 |
| `vertical_angles_deg` | number[] | `[0.0]` | 各线仰角，度，[-90,90]；非 spinning 模式必须为 [0]。 |
| `min_range_m` | number | `0.1` | 最小返回距离，m，≥0。 |
| `max_range_m` | number | `100.0` | 最大返回距离，m，必须大于最小距离。 |
| `horizontal_start_deg` | number | `-180.0` | 水平扫描起点，度；spinning/spherical/Mid-360 使用，rosette 保持默认。 |
| `horizontal_end_deg` | number | `180.0` | 水平扫描终点，度；大于起点且跨度 ≤360。 |
| `scan_mode` | string | `"snapshot"` | snapshot：同一真实位姿；rolling：按点时间从真实轨迹取样。 |
| `scan_pattern` | string | `"spinning"` | spinning / spherical / rosette / livox_mid360；后三者使用单条合成线。 |
| `vertical_min_deg` | number | `-90.0` | 非 spinning 垂直视场下界，度，[-90,90)；rosette 保持 -90。 Mid-360 建议覆盖其真实视场（例如 -7..52）；不自动改写默认值。 |
| `vertical_max_deg` | number | `90.0` | 垂直视场上界，度，大于下界且 ≤90；rosette 保持 90。 |
| `cone_half_angle_deg` | number | `19.2` | rosette 圆锥半角，度，(0,90]；其它模式不使用。 |
| `pattern_hz` | number | `100.0` | spherical/rosette 图案基频，Hz，(0,10000]；点率至少为 4*sqrt(2)*此值。 |
| `pattern_file` | string | `""` | Mid-360 必填 CSV 路径，支持 package://；相对路径相对组合 URDF 目录。 其它模式必须为空；Mid-360 同时要求 columns*rate_hz=200000。 |
| `ring_delays_s` | number[] | `[]` | 每线相对列起点的延迟，s；空表示零，每项 [0,1/(rate_hz*columns))。 非空时长度等于线数；非 spinning 模式必须为空。 |
| `self_filter` | string | `"sensor_link"` | 自身过滤模式：sensor_link / robot / links。 |
| `excluded_links` | string[] | `[]` | 额外排除的 URDF link；links 模式只排除此列表，robot 模式排除整个机器人。 |
| `range_bias_m` | number | `0.0` | 量程固定偏差，m，有限数。 |
| `range_sigma_m` | number | `0.0` | 独立高斯距离噪声标准差，m，≥0；按实例和帧/点确定性生成。 |
| `dropout` | number | `0.0` | 丢点概率，[0,1]；丢点为 NaN，不移动其它点的随机序列。 |
| `publish_range_boundary` | boolean | `false` | 发布 topic/range_boundary 人工量程边界；它不是实际激光回波。 |

未知字段、错误类型、非法数值或缺失必填项会在加载阶段报错。含禁用传感器的配置仍须满足参数与挂载要求。坐标/关节条件见[坐标与模型约定](../坐标与模型约定.md)。
