# litesim3d_imu

插件类：`litesim3d_imu/Imu`；类别：`SensorPlugin`。

本表所有参数在启动时读取。`number` 接受有限实数；数组长度、单位、范围和关联条件见说明列。
必填项没有默认值；请在机器人配置中提供实际值。可选项为实现缺省值，车型配置可以覆盖。

来源：[parameters.yaml](../../../plugins/litesim3d_imu/config/parameters.yaml)、[实现](../../../plugins/litesim3d_imu/src/plugin.cpp)。

| 字段 | 类型 | 默认值 | 单位、范围与含义 |
| --- | --- | --- | --- |
| `link` | string | 无；必填 | 必填示例：URDF 安装 link；数据使用此 link 的轴向，右手坐标系。 |
| `topic` | string | 无；必填 | 必填示例：sensor_msgs/Imu 话题；多机器人使用相对话题。 |
| `enabled` | boolean | `true` | 是否启用采样；false 仍校验挂载和参数。 |
| `rate_hz` | number | `200.0` | 采样频率，Hz，(0,2000]。 |
| `gravity_mps2` | number | `9.81` | 世界 -Z 重力加速度大小，m/s²，有限且 >0；默认与 FAST-LIO 的 9.81 对齐；启动时生效。 |
| `accel_bias` | number[] | `[0.0,0.0,0.0]` | 安装坐标系 xyz 三轴加速度偏差，m/s²，有限数；含重力比力。 |
| `gyro_bias` | number[] | `[0.0,0.0,0.0]` | 安装坐标系 xyz 三轴角速度偏差，rad/s，有限数。 |
| `accel_sigma` | number[] | `[0.0,0.0,0.0]` | xyz 独立高斯加速度噪声标准差，m/s²，各项 ≥0。 |
| `gyro_sigma` | number[] | `[0.0,0.0,0.0]` | xyz 独立高斯角速度噪声标准差，rad/s，各项 ≥0。 |
| `accel_range_mps2` | number | `0.0` | 加速度每轴对称量程，m/s²，≥0；0 不裁剪，正值在偏差/噪声之后裁剪。 |
| `gyro_range_radps` | number | `0.0` | 角速度每轴对称量程，rad/s，≥0；0 不裁剪；不提供姿态估计。 |

未知字段、错误类型、非法数值或缺失必填项会在加载阶段报错。含禁用传感器的配置仍须满足参数与挂载要求。坐标/关节条件见[坐标与模型约定](../坐标与模型约定.md)。
