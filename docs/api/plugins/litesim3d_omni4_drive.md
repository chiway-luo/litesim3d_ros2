# litesim3d_omni4_drive

插件类：`litesim3d_omni4_drive/Omni4Drive`；类别：`ChassisPlugin`。

本表所有参数在启动时读取。`number` 接受有限实数；数组长度、单位、范围和关联条件见说明列。
必填项没有默认值；请在机器人配置中提供实际值。可选项为实现缺省值，车型配置可以覆盖。

来源：[parameters.yaml](../../../plugins/litesim3d_omni4_drive/config/parameters.yaml)、[实现](../../../plugins/litesim3d_omni4_drive/src/plugin.cpp)。

| 字段 | 类型 | 默认值 | 单位、范围与含义 |
| --- | --- | --- | --- |
| `wheels` | object[] | 无；必填 | 必填：普通全向轮约束列表，包含每个独立 continuous 驱动关节；不支持麦克纳姆滚子模型。 车体 x 前、y 左、z 上；数组顺序无物理意义，但每个 joint 必须唯一。 三轮/四轮驱动插件分别要求恰好 3/4 项；里程计允许 3 或 4 项；约束矩阵必须满秩。 |
| `wheels[].joint` | string | 无；必填 | 必填：独立驱动关节名称，必须存在于组合 URDF。 |
| `wheels[].x_m` | number | 无；必填 | 必填：轮中心相对 base 的 x 坐标，m，有限实数；须与 URDF 一致。 |
| `wheels[].y_m` | number | 无；必填 | 必填：轮中心相对 base 的 y 坐标，m，有限实数；须与 URDF 一致。 |
| `wheels[].rolling_angle_rad` | number | 无；必填 | 必填：轮正向滚动方向相对 +x 的逆时针角，rad；正轴为 [-sin(a),cos(a),0]。 |
| `wheels[].radius_m` | number | 无；必填 | 必填：本轮有效半径，m，必须 > 0；被动滚子允许垂直于滚动方向的自由运动。 |
| `limits` | object | 见子字段 | 驱动速度限制；车体 x 前、y 左、z 上，正 yaw 绕 +z。 |
| `limits.max_linear_speed_mps` | number | `1.0` | 平移速度向量模长上限，m/s，必须 > 0。 |
| `limits.max_angular_speed_radps` | number | `2.0` | 绕 +z 角速度绝对值上限，rad/s，必须 > 0。 |
| `limits.acceleration_mps2` | number | `0.5` | 平移加速度上限，m/s²，必须 > 0。 |
| `limits.deceleration_mps2` | number | `1.0` | 减速或反向时的平移加速度上限，m/s²，必须 > 0。 |
| `limits.angular_acceleration_radps2` | number | `2.0` | yaw 角加速度上限，rad/s²，必须 > 0。 |
| `limits.unlimited_acceleration` | boolean | `false` | true：忽略加速度限制但保留速度与关节限制；false：使用上述加速度。 |

未知字段、错误类型、非法数值或缺失必填项会在加载阶段报错。含禁用传感器的配置仍须满足参数与挂载要求。坐标/关节条件见[坐标与模型约定](../坐标与模型约定.md)。
