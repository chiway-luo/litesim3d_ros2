- M1 开发与验收平台：本机 macOS 27.0.1 arm64，`ros2h` 的 RoboStack ROS 2 Humble。环境只读复用，不修改全局配置。
- Linux 作为后续独立验证，不参与本轮 M1 通过率或关闭判定。2026-10-17 已完成的测试保留为补充历史证据：Ubuntu 22.04 arm64 官方云镜像，Lima 2.2.1 / macOS Virtualization.Framework，4 vCPU、6 GiB RAM；ROS 2 Humble 官方 deb，默认 Fast DDS。镜像版本、SHA-256 和隔离配置保存在 `evidence/linux/lima.yaml`，实际安装版本由 Linux 验收脚本采集。测试虚拟机不挂载主机目录，软件渲染 RViz 使用独立 Xvfb；不据此声明后续 Linux 版本或 M2 性能已验收。
- C++17 核心独立于 ROS；Eigen 双精度变换；urdfdom 解析 URDF 1.0 兼容子集；Assimp 导入 STL/OBJ/DAE；yaml-cpp 读取严格版本化配置。
- 射线：解析 box/sphere/cylinder，双面 triangle，静态 AABB BVH。碰撞：FCL 距离查询配合按最大表面速度界限的保守推进，覆盖平移与旋转扫掠。阻挡前保留 10 µm 安全间隙。
- 首个机器人：R01 几何差速机器人；R02 为同尺寸网格版本；R03 为关节测试模型。平地默认步长 5 ms，雷达 32×1024/10 Hz，odom 50 Hz，瞬时扫描，理想里程计。
- 传感器与碰撞几何独立选择。默认仅过滤雷达所在 link。纯坐标 link（没有 visual 且没有 collision）允许存在；有实体 visual 而没有 collision 默认拒绝。显式 visual 替代写入导入报告。
- M1 支持暂停、恢复、幂等单步；位姿初始化仅就绪态允许，已开始实验通过完整进程重启。M2 的在线协调重置、坡面、噪声、IMU、扫描畸变、算法和性能门禁不提前宣称完成。
- 测试使用 CTest/GoogleTest、pytest 和真实 ROS graph/TF；运行报告逐条区分 PASS、FAIL、BLOCKED、NOT_RUN。CI 配置存在不代表远端 CI 已执行。

接口固定：`Step.srv` 请求 `string request_id, uint32 steps`，响应 `bool success, uint8 code, string message, uint64 time_ns`；最多 10000 步，最多保存 4096 个请求 ID，满后拒绝新 ID，避免驱逐旧 ID 导致重复执行。`SetPose.srv` 只用于开始前初始化。错误码 0 成功、1 状态错误、2 参数错误、3 容量限制、4 request_id 内容冲突。服务使用墙钟执行器，暂停不阻塞响应。

测试与运行的输出写入本项目 `evidence/`，ROS 使用测试专属 domain 和 localhost，避免向现有机器人网络发送控制。
