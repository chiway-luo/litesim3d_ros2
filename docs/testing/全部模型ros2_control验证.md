# 全部模型与第三方控制器 ros2_control 验证

2026-10-23，本轮覆盖仓库已有运动模型，不新增麦克纳姆轮。结果针对本地开发树；未提交、推送或操作真实设备。使用方法见 [全部模型与第三方算法 ros2_control](../tutorials/全部模型与第三方算法ros2_control.md)，此前关节底盘的实现与证据见 [多底盘验证](多底盘ros2_control验证.md)。

后续 TF 故障调查与完整回归单独记录在 [阿克曼 TF 断言诊断](阿克曼TF断言诊断.md)。下表保留首次运行的原始结果，不能将独立复跑改写成首次全套通过；后续已复现启动失败后的 RSP 子进程残留，修复及从头完整回归记录见该页。

后续修复验证：完整入口从头执行 **504 项通过、0 失败**；默认跳过的 23 项已全部在补充环境中执行通过，另有 11 项教程原文通过。根因为失败启动后的 RSP 子进程残留；完整回归还发现并修复硬件线程快速析构竞态及旧 TF 测试的采样前提，详见上述记录。以下历史表格保持原样。

## 实现范围

- 差速、阿克曼、三轮/四轮普通全向继续使用关节 position/velocity 接口；原四轮车默认入口也改用独立 controller_manager。
- 速度运动学无人机使用同一个 LiteSimSystem 的 body GPIO，导出机体系 XYZ 速度和偏航角速度指令、实际位姿与速度状态。无须虚构旋翼关节。机体与独立可动关节可在同一报文中提交。
- BodyVelocityController 处理输入限幅、非有限输入、超时、时钟倒退和生命周期清零；硬件适配器处理资源申领、交接清零、反馈失联与仿真会话变化。
- 里程计、雷达、MID360、IMU、RGB/Depth/RGB-D 继续提供对应 ROS 数据。图像与点云不转换成可写标量资源，第三方算法消费这些话题或读取控制状态。
- 案例独立配置 RSP、控制管理器与参数文件，用 ld 调用公共 launch；机械、仿真和控制 Xacro 分开展开。公共 launch 不启动 RSP 或控制管理器，也不依赖 RSP 的节点名与命名空间。
- 新增独立定高 ControllerInterface 插件包，默认 COLCON_IGNORE。它从另一个工作空间构建，仅依赖标准 ROS 控制接口，不依赖仿真核心。

四轮车和无人机保留显式 legacy_twist 入口供原步进回归使用。上表的旧运动学回归不代替新控制链路测试：新用例另行启动真实 controller_manager、硬件插件和控制器，通过 DDS 观察实际运动与反馈。无人机机械模型全为固定关节，因此其默认入口不启动 joint_state_broadcaster。

ROS 桥接套件跳过了需要隔离安装环境的缺失输出插件负例，以及未启用的旧相机整套用例。三类相机与 ros2_control 并行的本轮用例另行运行并通过，不能据此把跳过项计为通过。

独立定高插件从世界高度 1.2 m 向 1.6 m 收敛，记录最终高度约 1.59154 m。构建与联调前后的 sim_node、核心库、硬件库 SHA-256 一致，证明本次算法接入没有修改这些安装二进制。该记录之后仅有核心源代码格式调整与重新构建，核心 181 项测试再次通过；两轮日志分别保存，不混用二进制指纹。

## 失败记录与修复

初次新案例测试发现无人机的旧雷达参数不能直接移入新插件声明，已按插件契约移除不适用字段，并修正四轮车 MID360 测试使用的接口选项。修正后三个默认控制案例通过。第三方测试初次把 Python 整数赋给 ROS 浮点字段，已修正测试输入类型并完成闭环复测。

旧案例合并执行时，阿克曼模型/TF 用例在最后的 `/tf_static` 发布者数量断言失败；此前机械模型、运动、里程计和传感器 TF 数值断言已通过。未改动该断言，换用独立 ROS domain 后同一用例通过；检查时未发现残留仿真节点。当时尚未证实根因，原合并运行不能写成全量通过。后续恢复前置的无人机导入错误，复现出 RSP 子进程残留与同 domain 下的双发布者，详见 [TF 根因与修复记录](阿克曼TF断言诊断.md)。原始失败日志与独立复跑日志均保留。

一次 pytest 合并收集因四轮测试的同级模块导入与 importlib 模式不兼容而终止；后续将四轮套件独立执行，未通过删用例或修改断言规避。构建中仍有已有 Geometry::motion 缺省初始化警告，以及系统 Xacro 的 Python 弃用警告。

## 证据与边界

本机工作空间的 `artifacts/evidence/unified-ros2-control-20261023/` 保存构建与测试日志、案例状态与控制 JSON、第三方插件二进制指纹、教程运行结果、文档结果和本轮修改文件摘要。失败日志保留在同一证据目录中。临时开发工作空间与证据目录不是安装后的运行依赖。

本轮验证的是关节位置/速度与水平姿态无人机的速度运动学控制，包含原有碰撞与运动限制。不提供 effort、旋翼推力、姿态飞控、自由落体、轮胎接触动力学或硬实时保证。定高插件读取的是理想世界高度，不等于真实传感器估计。

没有新增麦克纳姆轮，没有验证真实硬件、macOS ros2_control、外部 SLAM/Nav2 算法、全部 RViz/窗口交互或长时间稳定性。三类相机的实际渲染通过也不能替代完整桌面套件。当前未提交工作树的结果不代表远端分支或 CI 已通过。
