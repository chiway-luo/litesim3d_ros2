# litesim3d_diff_odometry

插件类：`litesim3d_diff_odometry/DifferentialOdometry`；类别：`OdometryPlugin`。

本表所有参数在启动时读取。`number` 接受有限实数；数组长度、单位、范围和关联条件见说明列。
必填项没有默认值；请在机器人配置中提供实际值。可选项为实现缺省值，车型配置可以覆盖。

来源：[parameters.yaml](../../../plugins/litesim3d_diff_odometry/config/parameters.yaml)、[实现](../../../plugins/litesim3d_diff_odometry/src/plugin.cpp)。

轮径来自轮 link 的居中共轴圆柱 collision；轮位与轴向来自完整 URDF 的关节树。启动时先解析模型几何，再校验完整参数。旧参数若与模型冲突会报错，不能用于补齐缺失的模型。 `wheel_radius_m`、`wheel_separation_m` 自动生成。

| 字段 | 类型 | 默认值 | 单位、范围与含义 |
| --- | --- | --- | --- |
| `left_joints` | string[] | 无；必填 | 必填：左侧独立 continuous 驱动关节；正轴为车体 +y，正转使车体向 +x。 同侧独立多轮可列多个名称；URDF mimic 从轮不重复列入。 |
| `right_joints` | string[] | 无；必填 | 必填：右侧独立驱动关节，约定同左侧；左右集合不可重名。 |
| `noise` | object | 见子字段 | 编码器解算后的速度误差；位姿按每个实际时间段积分，reset 重置随机序列。 |
| `noise.linear_scale_error` | number[] | `[0.0,0.0]` | [x,y] 速度相对比例误差，无量纲，每项 > -1；0 理想，0.02 表示 +2%。 |
| `noise.angular_scale_error` | number | `0.0` | yaw 角速度相对比例误差，无量纲，> -1；0 理想。 |
| `noise.linear_scale` | number[] | `[1.0,1.0]` | 兼容旧配置：速度倍率，理想为 1；不能和非零 linear_scale_error 同时使用。 |
| `noise.linear_bias_mps` | number[] | `[0.0,0.0]` | 车体 [x,y] 两方向速度偏置，m/s，有限实数；非零可造成静止漂移。 |
| `noise.linear_sigma_mps` | number[] | `[0.0,0.0]` | 车体 [x,y] 两方向独立高斯速度噪声标准差，m/s，每项 >= 0。 |
| `noise.angular_scale` | number | `1.0` | 兼容旧配置：yaw 速度倍率，理想为 1；不能和非零 angular_scale_error 同时使用。 |
| `noise.angular_bias_radps` | number | `0.0` | yaw 速度偏置，rad/s，有限实数。 |
| `noise.angular_sigma_radps` | number | `0.0` | yaw 高斯速度噪声标准差，rad/s，必须 >= 0；seed 来自仿真。 |

未知字段、错误类型、非法数值或缺失必填项会在加载阶段报错。含禁用传感器的配置仍须满足参数与挂载要求。坐标/关节条件见[坐标与模型约定](../坐标与模型约定.md)。
