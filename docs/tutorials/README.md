# 入门教程

环境为 Ubuntu 22.04 + ROS 2 Humble + Bash。有自己的 description、希望从克隆开始搭建环境时，优先运行第一篇完整工程教程。后三篇为基础练习，先完成[安装与构建](../usage/安装与构建.md)，共用四轮车和办公场景。完成一个教程后停止其仿真，再进入下一个。

| 教程 | 学会什么 | 完成标志 |
| --- | --- | --- |
| [双 MID-360 从零搭建](双MID360从零搭建.md) | 从克隆到独立 description / bringup、world、URDF 传感器和 launch 配置 | 用自己的 bringup 启动场景、双雷达与 RViz |
| [阿克曼与全向轮接入 ros2_control](阿克曼与全向轮ros2_control.md) | world、关节接口、控制器、ld launch 与第三方算法接管 | 三类底盘均通过 ros2_control 驱动与反馈 |
| [全部模型与第三方算法 ros2_control](全部模型与第三方算法ros2_control.md) | 四轮车、无人机、传感器接口、独立算法插件构建与切换 | 所有现有模型使用统一资源接口，第三方控制器可独立接管 |
| [启动并控制小车](启动与控制.md) | 加载环境、启动仿真、读取传感器、发送速度、退出 | 数据连通，控制后里程计位移超过 1 cm |
| [添加一个 IMU](添加IMU.md) | 在自己的组合模型中添加安装坐标、固定关节和插件 | `/imu/tutorial` 有消息，frame 和安装 TF 正确 |
| [编写 ROS 2 消费节点](ROS2接入.md) | 使用仿真时间、匹配 QoS、订阅数据并显式启用控制 | 客户端输出 `success: true`，可正确识别缺失输入 |

完成后按任务进入[使用手册](../usage/README.md)；查询字段、单位和限制进入[接口参考](../api/README.md)。
