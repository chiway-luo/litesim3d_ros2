## 本轮启用范围

- 动态实体：恒定世界坐标线速度和绕世界 z 轴角速度；以每个点的采样时间求位姿，支持碰撞和感知。动态支撑面不支持，非法配置拒绝。碰撞使用保守相对扫掠速度包络，可能接触前机器人与动态障碍停止，停止时刻保留；不模拟接触力、反弹或自动绕行。相对碰撞包络包含支撑投影的高度变化；存在倾斜支撑时使用覆盖任意姿态变化的保守旋转界，可能更早停车。
- 多机器人：同一个世界、1–4 个同构 URDF/配置机器人；统一物理步和唯一 `/clock`，全部推进后再生成点云。按机器人 ID 隔离命令、话题、TF 和随机流；彼此以 URDF collision 几何感知。Shape/mesh 对象共享，机器人状态、轨迹、日志和 ROS 通道独立；射线工作线程最多 4 个，机器人依次计算，不乘以机器人数量。
- 底盘：`ackermann` 理想后轴参考点自行车运动学，输入线速度/角速度；轴距和最大转向角约束曲率，支持倒车，禁止原地转向。本轮使用 R01 等效后轴几何，不声明前轮转向关节、悬架或动力学。
- 雷达扩展：保留通用旋转方向序列，新增 Ouster `original` 字段适配器；不声明商业激光器的光学、标定或噪声真实性。实际消费算法为本机安装的 PCL `VoxelGrid`，读取所有厂商字段后进行体素降采样；这不等于 SLAM/Nav2 验收。

## 字段冻结

参考 Ouster 官方 [os_point.h（19071eb1）](https://github.com/ouster-lidar/ouster-ros/blob/19071eb14e0c8fecf0d94d1b2399aea5f44d549c/ouster-ros/include/ouster_ros/os_point.h) 和 [相对时间说明](https://github.com/ouster-lidar/ouster-ros/discussions/206)。输出小端、48 字节点步长，保留原组织维度和 header；字段布局由独立字节断言及 PCL 注册类型共同验证。

| 字段 | 偏移/类型 | 语义 |
| --- | --- | --- |
| x/y/z | 0/4/8，float32 | 米，坐标不变 |
| intensity | 16，float32 | 仿真归一化强度，非真实信号光子数 |
| t | 20，uint32 | 相对 header 的纳秒，源 time 秒值四舍五入 |
| reflectivity | 24，uint16 | 有效点的仿真强度 × 65535 四舍五入，非真实标定反射率 |
| ring | 26，uint16 | 原始线号 |
| ambient | 28，uint16 | 0（未建模） |
| range | 32，uint32 | 距离毫米，无效点 0 |

偏移 12 为 PCL 齐次坐标 1，其余填充字节为 0；无回波 xyz 保留 NaN。越界时间、布局、长度、强度和范围拒绝整帧；队列 KEEP_LAST 5。

## B3 性能门禁（结果产生前冻结）

场景沿用 F09：100,000 三角形、20×20×4 m 房间。4 个机器人位于 (-3,-3)、(3,-3)、(-3,3)、(3,3)，各 16×512 点、10 Hz、滚动扫描；200 Hz IMU、50 Hz odom、5 ms 步长，统一射线线程预算 4。本轮 B3 为无 GUI 共享世界负载；已有单机器人 GUI 功能纳入回归。

每种节拍预热 30 秒、采样 120 秒、重复 5 次，必须每次通过：无节拍 RTF ≥ 1；有节拍 RTF 在 [0.98,1.02]；内部漏帧 0；单帧射线计算 p99 ≤ 80 ms；计算完成至 ROS 发布完成 p99 ≤ 20 ms；仿真核心与桥接进程树峰值 RSS ≤ 1 GiB。CPU 按单逻辑核 100% 统计；RSP、接收器另列。记录原始采样、B0 环境、配置/资源/源码哈希；测试期间不并行运行构建和其他基准。不得把 120 秒性能窗口视为长期稳定验证。

## 追踪

T-EXT-01 至 T-EXT-06 分别对应动态逐点参考、相对扫掠、2/4 机器人隔离、B3 与随机流、Ackermann 解析/反馈闭环、适配字节与实际 PCL 消费。结果及可执行入口汇总在 M3 测试报告。未启用全向底盘、非重复扫描等扩展继续保留在路线图。
