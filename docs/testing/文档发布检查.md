## 审核与修正

| 问题 | 修正 |
| --- | --- |
| 首页混杂操作、性能成绩与历史验收决定 | 首页聚焦环境、clone、构建、运行；使用与测试分别进入 `docs/usage/`、`docs/testing/` |

| 文档检查强制依赖本机历史日志 | 新增 `check_repository_docs.py`，可在干净检出独立执行；历史证据审计入口保留 |
